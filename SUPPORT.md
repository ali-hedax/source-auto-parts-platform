# Support

| Need | Where to go |
| --- | --- |
| Reproducible software bug | Open an issue using the bug-report template |
| Proposed product improvement | Open an issue using the feature-request template |
| Security vulnerability or account/data issue | Contact the owner privately; see [SECURITY.md](SECURITY.md) |
| Setup or deployment | [README.fa.md](README.fa.md), [deployment](docs/DEPLOYMENT.md) and [current status](docs/DEPLOYMENT_STATUS.md) |
| Operator workflow | [Admin guide](docs/ADMIN_GUIDE.md) |

Issues may be written in Persian or English. Use screenshots with demonstration data and remove personal information, tokens, cookies and server credentials. Public issues are not a customer-support ticket system.

فارسی: برای باگ و پیشنهاد محصول از issue استفاده کنید. موضوعات حساب، اطلاعات مشتری و امنیت را خصوصی مطرح کنید. این مخزن عمومی است.
