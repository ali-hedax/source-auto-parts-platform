## Reading status and evidence

`DEPLOYMENT_STATUS.md` records public release readiness; private server observations are kept out of this repository. Historical test reports describe the environment and date in which each test ran; local tests do not demonstrate public HTTPS or real payment/SMS acceptance.

Do not put deployment secrets, customer exports or private server logs in this documentation directory.
