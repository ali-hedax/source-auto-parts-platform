## تفاوت‌ها و شکاف‌ها

- متن‌های عمومی Montserrat و Vazirmatn را حفظ می‌کنند. طبق بازبینی مالک، شعار بنر با JetBrains Mono و Vazir Code و تأکیدهای انگلیسی با Cormorant نمونه اجرا می‌شوند؛ قلم‌ها محلی‌اند و مجوزشان کنار فایل‌ها ثبت شده است.
- داده‌های قیمت روز و آپارات هنوز متصل نیستند. وضعیت انتظار، راهنمای ثابت و دکمهٔ غیرفعال صادقانه حفظ شده‌اند؛ قیمت یا بازدید ساختگی نمایش داده نمی‌شود.
- موجودی و محصولات واقعی از کاتالوگ می‌آیند؛ ترکیب و تعداد کالاهای ساختگی پیش‌نمایش به دادهٔ واقعی تحمیل نشده است.
- بنر عکس تازه دارد؛ فیلم آغازین موجود CMS در بخش مستقل بلافاصله پس از بنر محفوظ است. فیلم پایانی CMS حفظ شده و در نبود بلاک پایانی، فیلم تأییدشدهٔ مالک نمایش داده می‌شود. ردیف مستقل سازندگان طبق درخواست تازهٔ مالک در خانه نمایش داده نمی‌شود.
- چهار تصویر برند و کارت پنجم SOURCE، تفسیر تزئینیِ تأییدشده در گفتگو هستند. برای برند جدید، نام/لوگوی ثبت‌شده fallback می‌ماند؛ نشان ساختگی برای برند ناشناخته تولید نمی‌شود.
- نام برند و شمارش واقعی برای صفحه‌خوان حفظ می‌شود؛ زیر artwork نام تکراری بصری ندارد.
- تنظیمات ذخیره‌شدهٔ مدیر محترم هستند؛ رنگ، لوگو یا جای هکسی که قبلاً صریحاً انتخاب شده، با مهاجرت داده بازنویسی نشده است. برای rollout باید پیش‌نویس Appearance با همین preset بررسی و به‌طور جداگانه منتشر شود.
- اسکرین‌شات‌ها فقط fixture محلی هستند؛ وضعیت اتصال مدل یا عملیات تولید را اثبات نمی‌کنند. نمایش پیام/اپراتور از پاسخ‌های مصنوعیِ صریح آزمون استفاده می‌کند، نه دادهٔ مشتری.

## انتشار بعد از تأیید جداگانه

تغییر کاربردیِ این PR در وب و مقدار پیش‌فرض جای هکسی در قرارداد مشترک است؛ API/DB/migration تازه‌ای اضافه نشده است. پیش‌نیاز انتشار با توجه به پایهٔ PR58: وضعیت rollout و migration اپراتورِ همان PR باید در زمان انتشار بررسی شود؛ این PR آن مرحله را اجرا یا تکرار نمی‌کند. برای این طراحی migration جدیدی لازم نیست. نسخهٔ قبلی وب و نسخهٔ منتشرشدهٔ Builder برای rollback حفظ شوند.

نتیجهٔ آزمون‌ها و تصاویر نهایی پس از اجرا در همین پوشه ثبت می‌شود.

پس از بازبینی تازهٔ مالک، نوار جستجو تنها یک باکس دارد و ردیف میان‌برها حذف شد. چهار انتخاب واقعی خودرو و تمام مسیرهای خرید/درخواست تأمین محفوظ‌اند. اصلاح ماسک تلفن PR60 از main حفظ شد؛ کد سرور آن جزو diff این PR نیست.
