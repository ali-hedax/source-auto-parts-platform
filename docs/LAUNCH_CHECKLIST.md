# چک‌لیست راه‌اندازی فروش واقعی

آغاز فروش واقعی مرحله‌ای جدا از ساخت محلی است (بند ۲۲). این فهرست فقط موارد **واقعاً باقی‌مانده** را دارد. «مالک» یعنی تصمیم یا تهیهٔ بیرونی لازم است؛ «فنی» یعنی پس از تصمیم مالک، کار توسعه یا اجرا لازم است.

## ۱. زیرساخت

| مورد | مسئول | وضعیت |
| --- | --- | --- |
| انتخاب و تهیهٔ دامنه | مالک | انجام نشده |
| انتخاب ارائه‌دهندهٔ سرور (دسترسی کاربران ایران، شرایط درگاه/پیامک) و تهیهٔ VPS | مالک | انجام نشده |
| ذخیره‌ساز شیء خصوصی/عمومی (یا شروع با درایور local و پشتیبان بیرونی) | مالک + فنی | انجام نشده |
| اجرای `infra/docker-compose.yml` روی سرور و آزمون پذیرش استقرار ([`DEPLOYMENT.md`](DEPLOYMENT.md) بخش ۵) | فنی | **اجرا نشده** (Docker در محیط ساخت نبود) |
| ClamAV واقعی و آزمون فایل EICAR | فنی | **اجرا نشده** |
| Redis/BullMQ واقعی: اسکن، Excel، PDF و تطبیق از طریق صف | فنی | **اجرا نشده** (منطق با فراخوانی مستقیم سرویس آزموده شده) |
| پشتیبان‌گیری خودکار بیرون از سرور + یک بازیابی کامل آزمایشی با `pg_dump`/`pg_restore` | فنی | **اجرا نشده** (مانور سطح فایل محلی پاس شد) |
| پایش و هشدار (readiness، دیسک، صف، پشتیبان، TLS، ساعت) | فنی | انجام نشده |
| آزمون بار با دادهٔ نمونه برای برآورد ظرفیت | فنی | انجام نشده |
