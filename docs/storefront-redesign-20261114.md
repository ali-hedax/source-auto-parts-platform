## یادداشت‌های فنی
- فشرده‌سازی: Caddy از قبل `encode zstd gzip` دارد؛ HTML، CSS و JS روی سایت زنده gzip می‌رسند (بررسی 2026-11-14 با
  `Accept-Encoding`). Brotli افزونهٔ جداگانهٔ Caddy می‌خواهد و لازم نیست. سایت پشت CDN آروان نیست.
- درخواست تأمین بدون ورود: `POST /api/v1/sourcing-requests/guest` (multipart: `payload` + حداکثر ۳ عکس). محدودیت:
  ۵ در ساعت و ۱۵ در روز برای هر IP، ۵ در روز برای هر شماره؛ فیلد تلهٔ مخفی برای ربات. حساب مشتری با همان شماره ساخته یا به
  حساب موجود وصل می‌شود؛ پاسخ API نمی‌گوید حساب از قبل بوده یا نه. شمارهٔ موبایل تا ورود با کد تأیید «تأییدنشده» است و این
  در یادداشت درخواست برای کارشناس نوشته می‌شود. کپچا اضافه نشده است.
- سال شمسی (۱۳۰۰ تا ۱۴۹۹) در درخواست مهمان در متن مدل/تیپ نگه داشته می‌شود، چون ستون سال در پایگاه داده فقط ۱۹۵۰ تا ۲۱۰۰
  را می‌پذیرد (بدون migration).
