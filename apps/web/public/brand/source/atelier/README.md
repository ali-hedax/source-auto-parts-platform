# SOURCE atelier artwork

Owner-reviewed concept artwork from the design conversation, 2026-10-28.
Encoded as WebP using the already-installed Sharp image encoder. No runtime image
library or new dependency was added. Next Image serves appropriately sized files
from this narrowly allowlisted namespace. Original source files remain outside
the repository; no private customer or supplier images are included.

- `hero.webp`: editorial automotive scene, not a photograph of an offered vehicle.
- `category-0..5.webp`: illustrative category covers, not product photos.
- `hub-0..2.webp`: editorial covers; no price/video feed is implied.
- `brand-*.webp`: owner-requested bronze/travertine interpretations of four
  existing emblems. Used only for the home editorial cards; canonical catalogue
  logos and uploaded brand records are retained.
- `logo.webp`: warm bronze variation of the existing SOURCE wordmark.
- `hexi.webp`: transparent warm-colour variation of the owner-provided mascot.

Home and cover images can be replaced in Website management → Home design.
Header logo overrides remain in the existing Appearance logo controls; Hexi's
avatar, copy, placement and size remain in the existing Assistant controls.
