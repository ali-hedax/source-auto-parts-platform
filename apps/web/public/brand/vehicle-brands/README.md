# آرم برندهای خودرو

برای این‌که آرم یک برند به‌جای نامش روی صفحهٔ اصلی و صفحهٔ «برندها» نشان داده شود، فایل آرم را با نام دقیق اسلاگ برند در همین پوشه بگذار:

| برند | نام فایل |
| --- | --- |
| ایران خودرو | `iran-khodro.svg` (یا `.png`) |
| سایپا | `saipa.svg` |
| تویوتا | `toyota.svg` |
| هیوندای | `hyundai.svg` |

اسلاگ هر برند تازه را از آدرس صفحه‌اش می‌بینی: `sourcebyhedax.ir/fa/brands/<اسلاگ>`.

- فرمت ترجیحی SVG است (شفاف و واضح در هر اندازه)؛ PNG یا WebP با پس‌زمینهٔ شفاف هم کار می‌کند.
- ارتفاع نمایش حدود ۳۶ پیکسل است؛ فایلی با ارتفاع حداقل ۱۲۰ پیکسل کافی و واضح است.
- فایل آرم باید خودِ آرم رسمی برند باشد (مثلاً از صفحهٔ رسانه‌ای/پرس‌کیت همان برند)؛ من چیزی شبیه‌سازی‌شده نساختم چون آرم هر برند علامت تجاری آن شرکت است.
- اگر فایلی برای یک برند نباشد، همان طراحی فعلی (فقط نام برند) نمایش داده می‌شود؛ چیزی خراب نمی‌شود.
